## 1.实验目标：
安装 VS Code，配置 Markdown 写作插件，创建并预览第一个 Markdown 文件。
## 2.实验环境：
| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11 专业版 22H2 |
| 核心软件 | Visual Studio Code 1.128.0 |
## 3.核心操作记录：
（1）安装 VS Code：从官网下载并安装，务必勾选“添加到 PATH”。
（2）安装插件：在扩展面板中搜索并安装 Markdown All in One 和 Markdown Preview Enhanced 插件。
（3）编写 Markdown 文件：新建 test.md 文件，输入标题、列表、代码块等基本语法。
（4）预览效果：使用 Ctrl+K V 打开并排预览窗口。

## 5.知识总结
| 知识点 | 核心内容 |
|--------|----------|
| VS Code 插件 | Markdown All in One（目录、快捷键）、Markdown Preview Enhanced（预览、导出 PDF） |
| Markdown 语法 | 标题（#）、列表（-）、代码块（```）、图片（![]()）、表格（\|） |
| 编辑器配置 | 自动保存（files.autosave）、单词折行（editor.wordwrap） |
| Markdown 预览 | `Ctrl+K V` 并排预览 |
