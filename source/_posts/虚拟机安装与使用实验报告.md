## 1、实验目的
本次实验旨在掌握虚拟化技术的基本应用，通过在 Windows 宿主机上使用 VirtualBox 安装 Ubuntu Server 22.04 LTS 操作系统，并利用克隆技术构建一个包含三台虚拟节点的多机实验环境，为后续的 Linux 环境配置、远程登录管理和软件部署实验提供基础平台。

## 2、实验环境
| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11/10 专业版（宿主机）|
| 虚拟化软件 | Oracle VirtualBox 7.0 |
| 虚拟机操作系统 | Ubuntu Server 22.04.5 LTS (amd64) |
| 硬件配置 | 宿主机内存 16GB（分配虚拟机 2GB/台），CPU 支持 VT-x/AMD-V |
| 网络拓扑 | 双网卡模式（NAT 用于外网访问，Host-Only 网段 192.168.56.0/24 用于多机互联）|
## 3、实验过程（图文并茂）
### 步骤一：下载与安装 VirtualBox 及 Ubuntu ISO
访问 VirtualBox 官网下载 Windows 安装包并完成安装。同时，从国内镜像站（如中科大镜像源）下载 ubuntu-22.04.5-live-server-amd64.iso 镜像文件备用。
### 步骤二：创建模板虚拟机并配置双网卡
在 VirtualBox 中点击“新建”，名称设为 ubuntu-template，类型选 Linux，版本选 Ubuntu (64-bit)。分配内存 2048 MB，硬盘创建为 VDI 格式、动态分配，大小 20 GB。在“设置 -> 网络”中，启用两个网络适配器：
适配器 1：NAT（用于联网下载）
适配器 2：仅主机(Host-Only)网络（用于内网互通）
![NAT网卡](./images/NAT网卡.png)
![仅主机网卡](./images/仅主机网卡.png)
### 步骤三：安装 Ubuntu Server 操作系统
启动虚拟机，加载 ISO 镜像。按照引导完成安装（语言 English，键盘布局 English US）。在“Profile setup”步骤设置用户名（如 dev）和密码。关键操作：在“SSH Server”配置步骤，务必按空格键选中 “Install OpenSSH server”。安装完成后重启。

### 步骤四：配置静态 IP 与主机名解析
登录模板机，修改 Netplan 配置文件使 Host-Only 网卡 IP 固定为 192.168.56.101：

bash
sudo nano /etc/netplan/50-cloud-init.yaml
修改 enp0s8 为 dhcp4: no，添加 addresses: [192.168.56.101/24]
sudo netplan apply
同时修改主机名并配置 hosts 文件，以便后续使用主机名直接访问：

bash
sudo hostnamectl set-hostname template
sudo nano /etc/hosts
添加映射：192.168.56.101 template 等
![netplan配置](./images/netplan配置文件.png)
### 步骤五：克隆生成多台虚拟机
关闭模板机（sudo shutdown now）。在 VirtualBox 中右键 ubuntu-template，选择“克隆”，克隆类型选择 “完全克隆”，分别命名为 node1、node2、node3。克隆完成后，依次启动各节点，并使用 sudo hostnamectl set-hostname nodeX 和修改 /etc/netplan/... 中的 IP 地址（分别改为 .102、.103、.104）使其差异化。

![VirtualBox 管理器中显示多台克隆机列表](./images/虚拟机列表.png)

### 步骤六：验证多机网络连通性
在 node1 终端中分别测试外网连通性（NAT）、宿主机连通性（Host-Only 网关）以及内网节点互通性（Host-Only 主机名解析）。

bash
ping -c 3 8.8.8.8
ping -c 3 192.168.56.1
ping -c 3 node2

## 4、实验结果
通过本次实验，成功在单台物理机上构建了由 1 台模板机和 3 台克隆机组成的虚拟化集群环境。所有节点均可通过 Host-Only 网络实现互连，且均能通过 NAT 网卡访问互联网。

| 测试项 | 源节点 | 目标节点/地址 | 结果 |
|--------|--------|---------------|------|
|NAT 上网连通性 | node1 | 8.8.8.8	| ✅ 成功 |
|Host-Only 宿主机连通| node1 | 192.168.56.1	| ✅ 成功 |
|内网主机名解析 | node1	| node2 (192.168.56.102) | ✅ 成功 |
|内网主机名解析	| node1	| node3 (192.168.56.103) | ✅ 成功 |
## 5、知识总结
本次实验涉及的核心知识点总结如下表：

| 知识点 | 内容说明	| 本实验应用 |
|---------|---------|-----------|
|虚拟化技术	| 在宿主机上模拟完整硬件环境运行独立操作系统 | VirtualBox 运行 Ubuntu Server |
|NAT 模式 | 虚拟机通过宿主机 IP 访问外网，外部无法直接访问虚拟机 | 用于 apt 更新和软件下载 |
|Host-Only 模式	| 宿主机与虚拟机组成隔离的私有局域网 | 用于 node1/2/3 之间的 SSH 免密内网通信 |
|克隆技术 | 完全克隆生成独立的新虚拟机，拥有独立的 MAC 和磁盘 | 快速构建多机实验环境（node1-3） |
|Netplan 配置 | Ubuntu 默认的网络配置工具，使用 YAML 语法 | 配置 enp0s8 网卡的静态 IP |
## 6、出现问题与解决方案
| 问题现象 | 可能原因 | 解决方法 |
|-----------|---------|---------|
|启动虚拟机提示“VT-x/AMD-V 未启用” | BIOS 中未开启硬件虚拟化支持 | 重启电脑进入 BIOS，开启 Intel VT-x 或 AMD SVM 功能 |
|克隆后的 node2 无法 ping 通 node1 | 克隆机保留了原网卡的 MAC 地址，或 IP 冲突 | 在 VirtualBox 中为克隆机“重新生成 MAC 地址”，并修改静态 IP |
|sudo netplan apply 报错 | YAML 文件缩进不正确 | 检查 YAML 缩进（必须使用空格，不能用 Tab）|
